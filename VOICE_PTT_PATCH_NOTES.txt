SAFE INSTALL:
1. Close Lily completely.
2. Make a copy/backup of the whole Lily project folder.
3. Extract this ZIP into the existing project root, preserving folder paths,
   and allow only the listed files to be overwritten.
4. Do not replace or delete memory.json, config/local_settings.json,
   config/api_keys.json, or any backup files. They are not in this ZIP.

FIRST MICROPHONE TEST:
  py -3.8 mic_level_test.py

Stay quiet for PHASE 1 and speak continuously during PHASE 2. The report compares
levels over time rather than using a single peak value. If the two phases look
the same, test each available Realtek endpoint listed by the script, for example:
  py -3.8 mic_level_test.py 1
  py -3.8 mic_level_test.py 5
  py -3.8 mic_level_test.py 9
Only select an index that clearly responds to speech. If one does, add
"mic_device_index": <that index> to config/local_settings.json, then restart Lily.
Leave the setting absent or null until an index has been verified.

CTRL+SPACE TEST:
1. In Lily's HUD, turn PUSH-TO-TALK: Ctrl+Space ON.
2. Hold Ctrl+Space, speak a short sentence, and release the keys.
3. Expect Lily to transcribe/respond after release, once.
4. Restart Lily while the saved option is ON and verify the hotkey works without
   toggling it off and on again.
A global hotkey works with other windows in front; the Qt/window fallback works
while Lily has focus. Recognition through Google needs Internet unless Vosk has
been configured.
